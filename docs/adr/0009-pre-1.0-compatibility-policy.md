# 1.0 前只在 patch 版本内承诺兼容

Colla 在同一版本中始终保证 Rust crate 与 `colla-ot` 的公共语义和规范字节完全一致；
`0.1.x` 的 patch 版本保持公共 API 与 wire compatibility，但 `0.2.0` 等 minor 版本在提供
迁移说明后可以破坏 API 或规范二进制格式。当前 codec 只有 canonical body，没有版本
envelope 或 migration 机制，因此 1.0 前不承诺跨 minor 直接读取长期持久化数据；到 1.0
再承诺稳定公共 API 与长期 wire compatibility，避免在真实消费者验证前过早锁死模型。

可发布的 `colla` crate 以 Rust 1.81 为 MSRV，并在 manifest 与 CI 中显式验证 library
构建；完整 tests、clippy、rustdoc 和 bench 使用受支持的最新 stable。私有 `colla-wasm`
构建层不共享该 MSRV。1.0 后提高 MSRV 至少需要 minor 版本并记录在 changelog 中。

`colla-ot` 0.1 以仍受官方支持的 Node.js 22 为最低版本，并在 Node 22 与 24 上验证；
不为发布时已经 EOL 的 Node 20 建立新承诺。提高最低 Node 版本至少需要 minor 版本，
1.0 发布时再根据当时仍受支持的 LTS 重新确认基线。Vite 5+ 与 Rollup 4+ 的 bundler
基线独立维护。
