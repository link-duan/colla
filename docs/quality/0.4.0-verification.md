# Colla 0.4.0 实现与验收记录

2026-09-11：本地实现和下述验收完成，尚未发布。当前开发版本为 `0.4.0`，
采用版本 2 编码，未提供旧 API 或版本 1 编码兼容层。

## 实现范围

- Rust Core：稳定 ElementId、不可变树和父关系索引、弱 Ref 与反向查询、复制引用重映射、
  原生跨父 Move、规范操作序列，以及带内容基准的 apply/invert/compose/transform。
- Editing：完整 Map/List/Text/RichText/Int 编辑，UTF-16 边界转换，原子事务，身份保留的
  editSteps，失效作用域，提交后事件及监听器隔离。
- Rust 协作引擎：History、不可变 Authority、SyncSession、原始在途请求与缓冲、正式 Commit
  确认、去重、revision 缺口、历史裁剪、恢复状态，以及内容/同步/完整运行态的独立检查点。
- JavaScript：同步 facade、不可变公开对象、受控协议对象和严格版本 2 Rust codec。
  公开代数只使用 `transform`，返回 `[leftAfterRight, rightAfterLeft]`。
- 文档、领域模型、ADR、示例、共享 fixtures、CHANGELOG 和包版本均已迁移。

## 体积与依赖

JS **零 npm 运行时依赖**。Rust Core 保留 cocodec/thiserror，仅新增 getrandom 作为安全随机
命名空间来源；wasm-bindgen/js-sys 沿用现有边界。serde_json 只用于测试 fixtures，不进入运行时。
旧结构 OT 和旧 codec 已移除，Text/RichText 的 scalar 算法继续以私有模块复用。

Node 和浏览器共用一份 base64 Wasm 数据，npm 包不再重复携带原始 Wasm，也不包含私有绑定的
类型声明。构建使用 size 优化、LTO、单 codegen unit、剥离符号和 wasm-opt `-Oz`。

以下均为字节数。浏览器 ESM 包含全部公开 API，关闭 tree shaking，包含内嵌 Wasm。
npm tarball 本身已经 gzip 压缩，不能与未压缩 Wasm 数字直接比较。

| 产物 | 0.3.0 基线 | 0.4.0 | 变化 |
| --- | ---: | ---: | ---: |
| Wasm 原始字节 | 421,242 | 439,307 | +4.3% |
| Wasm gzip | 145,868 | 166,897 | +14.4% |
| Wasm Brotli | 111,222 | 130,761 | +17.6% |
| 完整浏览器 ESM 原始字节 | 671,624 | 685,918 | +2.1% |
| 完整浏览器 ESM gzip | 219,263 | 242,737 | +10.7% |
| 完整浏览器 ESM Brotli | 169,659 | 190,660 | +12.4% |
| npm 安装 tarball | 578,744 | 478,195 | -17.4% |

npm 包缩小来自去掉重复载荷；新增身份、协作状态机和严格校验使 Wasm 本体及浏览器压缩入口
略有增长。不能将 npm 安装包变小解释为所有浏览器下载场景都变小。

[体积预算](../../packages/core/size-budget.json) 由 `measure` 检查，并已接入 CI quality-baseline：
Wasm 原始 500,000 B / gzip 190,000 B，完整浏览器 ESM gzip 275,000 B，npm tarball
550,000 B。预算为当前编译器差异留出余量；所有上限本次均通过，增加依赖需同时评估测量结果。

## 性能与内存

同一台 darwin/arm64、Node v26.7.0，Rust 1.97.1、wasm-pack 0.13.1。
旧基线由未修改提交 `d0ffba93386d44c1b7062647d589a97a946f0709` 单独构建。
操作记录 5 组样本的每次调用中位数；初始化来自 5 个独立进程。单位为毫秒。

| 操作 | 0.3.0 | 0.4.0 |
| --- | ---: | ---: |
| Node 同步初始化 | 4.725125 | 5.962667 |
| Value.fromJS + toJS | 0.021597 | 0.018041 |
| 旧 Builder / 新完整事务（工作量不同） | 0.013101 | 0.031115 |
| Apply | 0.000811 | 0.001716 |
| Compose | 0.000739 | 0.006533 |
| 双向 Transform | 0.002094 | 0.009466 |
| Value Encode | 0.000723 | 0.001386 |
| Value Decode | 0.002093 | 0.004615 |

新 Compose/Transform 会校验和读取完整内容基准，旧接口没有此契约；新事务还计算 inverse、
投影及协作运行态。以上是版本基线，不是相同工作量的性能提升证明。Node 从共享 base64
恢复 Wasm 有额外解码成本，换取减少重复产物。大文档性能应使用应用实际结构另测。

内存压力测试执行 6,000 次事务，同时创建并关闭临时 Document，主会话保持一条在途请求、
缓冲和最多 100 个 History 单元。预热后 Wasm 内存保持 2,031,616 B，JS 堆净增 3,944 B，
完整 SessionCheckpoint 保持 2,361 B。测试主动跨任务轮次触发 GC，检查 JS/Wasm 增长和
检查点大小。旧版 6,000 次 Document set 的 Wasm 从 1,966,080 B 增至 3,538,944 B；旧版
没有对应 History/SyncSession，工作量不同，不能据此推断通用内存收益。

Authority 为保证严格请求去重保留请求回执；裁剪日志不会清除去重回执。该服务端持久化开销
不包含在上述客户端内存测试中。

原始数据：[旧基线](0.3.0-baseline.json)、[旧补充测量](0.3.0-extra.json)、
[新基线](0.4.0-baseline.json)。可复跑：

```sh
pnpm --dir packages/core measure --output ../../docs/quality/0.4.0-baseline.json \
  --markdown-output ../../docs/quality/0.4.0-baseline.md
```

回归覆盖四类原缺陷：事务内接收远程 Commit 和关闭/嵌套重入、逃逸的 Transaction 与派生
编辑器、原始请求 bytes 与工作重基 Change 分离、外部修改输入/输出字节不影响内部状态。
自定义 thenable 不执行其 then 方法；真正 Promise 的返回同样使事务回滚。

性质验证包括 625 对单步 List Move、1,000 对多步 List 操作、1,000 对跨父多步操作及
两个优先级；同时覆盖 Map 换位、祖先/后代 Move、删除优先、Move 原始来源关联、占用与环冲突。
Unicode/RichText 属性测试检查 compose、invert 和 TP1；身份/Ref 测试覆盖 Copy/set 重映射、
Undo/Redo 身份恢复、悬空与循环、快照局部解析及 codec 往返。

三客户端模拟包含 180 轮随机本地编辑、延迟、重复投递、缓冲、重试和客户端/Authority
检查点重启；排空后全部可见内容与 Authority 按身份完全相等。另有缺口不提交、裁剪历史恢复、
结构拒绝保留工作、分组、Move 和 RichText 撤销后保留远程修改的定向测试。

Fuzz 冒烟：OT 31 秒 / 28,021 个输入；两个解码目标各 21 秒 / 1,184,621 和 757,778 个输入。
之后为两个解码目标增加“接受即保留原始规范 bytes”的断言，各额外运行 21 秒，均通过。
OT 目标对必须可合并的输入直接要求成功，禁止把变换错误当作跳过。
`python3 fuzz/seed.py` 从共享 fixtures 生成 35 个 v2 种子；CI 已接入，以覆盖合法协议/检查点分支。
这些有界测试提供回归证据，不代表穷尽所有可能状态。

## 发布边界

本地验收平台为 macOS arm64；仓库 CI 保留 Linux、Node 22/24 最低/最新打包器、三浏览器和
fuzz 矩阵，远端 CI 尚未在本次未提交工作树上运行。版本发布仍是独立动作。

此版本仅承诺中心化提交顺序下可合并操作的 TP1，不承诺 TP2、任意点对点合并或跨文档 Ref。
网络、持久化存储、鉴权与恢复时的业务合入由应用提供。
