# Data model

Data model topics are maintained as focused Wiki pages so each topic can carry
its examples and invariants without becoming a short, disconnected tab:

- [Values](/docs/core/values) — immutable scalar, sequence, and container values.
- [Changes](/docs/core/changes) — recursive operations and canonicalization.
- [Text](/docs/core/text) — Unicode-scalar text editing.
- [RichText](/docs/core/richtext) — attributed spans and atomic embeds.
- [Coordinates and paths](/docs/core/coordinates) — snapshot-relative lookup and
  UTF-16 projection.
